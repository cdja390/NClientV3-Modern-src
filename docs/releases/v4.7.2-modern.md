# NClientV3 Modern 4.7.2

正式应用名为 **NClientV3 Modern**。版本 `4.7.2-Modern`，`versionCode` 为 `470200`。签名 APK 需要 **Android 9（API 28）或以上**。

## 本版更新

- 主页和设置都能选择来源。NH 可以与 EH 混排，启用 ExHentai 后会使用 EX。
- 无筛选的主页增加「热门（日榜）」。第一页按两站各自的榜单顺序交替显示，后续页加载 NH 日榜。仅 EH／EX 时返回一页热门结果。带筛选的双站搜索使用「最近」。
- 本地收藏和历史按来源合并，在线收藏按选中的来源查询，本页批量下载按来源分流。
- EH 使用独立详情和阅读器，支持水平、垂直和条漫阅读、边缘和音量键翻页、自动翻页、续读与阅读统计。

## 覆盖升级

先在旧版 **设置 → 导出数据** 备份。ZIP 包含数据库和设置，已下载的图片文件单独保留。旧版与新版包名、签名证书相同时，Android 可原位覆盖。证书不匹配时请保留旧版和备份。 [备份格式](../BACKUP_FORMAT.md)

## 已验证范围

- 146 项 JVM 测试通过，零失败、零错误、零跳过。
- 小米 13 使用本页签名包从 4.7.0 原位升级。升级前后导出的 11 张主库表逐行一致，正式包联网显示 NH 和 EH 热门混排。
- 华为和小米的并存 Debug 均验证了热门混排和翻页。EX 联网、带既有记录的 EH 库迁移，以及部分真机异常场景仍待验证。 [验收记录](../MERGE_ACCEPTANCE_472.md)
